# WhatsApp History Importer

Personal-use desktop app for importing WhatsApp message history (groups and 1:1 chats) into a local database with a faithful WhatsApp-Web-style UI.

> **Disclaimer:** This application is not affiliated with, endorsed by, or connected to WhatsApp LLC. Use only with your own account, for personal data you own. Your data never leaves your computer.

See `.hermes/plans/` for the implementation plan.
